# خطوات إضافة لون جديد لبوت الفينيل (مثال: بنفسجي - purple)

⚠️ **مهم جدًا:** فيه لونين مسار كامل بالبوت لازم تضيف اللون بهم **الاثنين**، وإلا اللون
يشتغل بمكان وما يظهر/ما يشتغل بالثاني:

1. **قائمة `/dev` + قائمة "🎨 لون القرص"** (`build_vinyl_color_keyboard` + `on_vinyl_choice`)
2. **معالج التخصيص "🎛 تخصيص" اللي يطلع بعد إرسال الملف الصوتي** (`build_wiz_color_keyboard` + `on_wiz_color`)

نسيان المسار الثاني (الـ Wizard) هو السبب الأشهر إن اللون "ما يظهر" لما ترسل ملف
وتضغط تخصيص — لأنه كيبورد منفصل تمامًا وفيه تحقق (validation) منفصل من القيم المسموحة.

### ج) on_vinyl_choice — أضف "purple" لقائمة الألوان المقبولة

⚠️ هذا أهم سطر ينسى — لو اللون مو موجود بهذي القائمة، اختيار المستخدم يُتجاهل
ويرجع تلقائيًا للون الافتراضي (default) حتى لو الزر نفسه ظاهر بالكيبورد.

```python
@router.callback_query(F.data.startswith("vinyl:"))
async def on_vinyl_choice(callback, bot: Bot):
    choice = callback.data.split(":", 1)[1]
    user_id = callback.from_user.id if callback.from_user else 0
    if choice in ("pink", "blue", "yellow", "red", "green", "bloody", "purple"):  # 👈 أضف هنا
        developer_vinyl_choice[user_id] = choice
    else:
        developer_vinyl_choice.pop(user_id, None)
    await callback.message.edit_reply_markup(reply_markup=build_vinyl_color_keyboard(user_id))
    await callback.answer(texts_module.MSG_VINYL_CHOICE_SAVED_ANSWER)
```

### د) build_vinyl_color_keyboard — أضف الزر الجديد بالكيبورد

```python
def build_vinyl_color_keyboard(user_id: int = 0) -> InlineKeyboardMarkup:
    current = developer_vinyl_choice.get(user_id)

    def label(text: str, value: str) -> str:
        is_selected = current == value or (current is None and value == "default")
        return f"{text} ✅" if is_selected else text

    return InlineKeyboardMarkup(inline_keyboard=[
        [InlineKeyboardButton(text=label(texts_module.BTN_VINYL_BLACK, "default"), callback_data="vinyl:default")],
        [
            InlineKeyboardButton(text=label(texts_module.BTN_VINYL_PINK, "pink"), callback_data="vinyl:pink"),
            InlineKeyboardButton(text=label(texts_module.BTN_VINYL_BLUE, "blue"), callback_data="vinyl:blue"),
        ],
        [
            InlineKeyboardButton(text=label(texts_module.BTN_VINYL_YELLOW, "yellow"), callback_data="vinyl:yellow"),
            InlineKeyboardButton(text=label(texts_module.BTN_VINYL_RED, "red"), callback_data="vinyl:red"),
        ],
        [
            InlineKeyboardButton(text=label(texts_module.BTN_VINYL_GREEN, "green"), callback_data="vinyl:green"),
            InlineKeyboardButton(text=label(texts_module.BTN_VINYL_BLOODY, "bloody"), callback_data="vinyl:bloody"),
        ],
        [InlineKeyboardButton(text=label(texts_module.BTN_VINYL_PURPLE, "purple"), callback_data="vinyl:purple")],  # 👈 جديد
        [InlineKeyboardButton(text=texts_module.BTN_BACK, callback_data="vinyl_menu:back")],
    ])
```

هذا المسار يظهر لما المستخدم يرسل ملف صوتي ويضغط "🎛 تخصيص" (`mode:custom`).

### ب) on_wiz_color — أضف "purple" لقائمة القيم المقبولة

⚠️ **هذا هو السطر اللي غالبًا كان ناقص عندك.** بدونه، اختيار اللون الجديد بالـ
wizard يُتجاهل ويرجع تلقائيًا للأسود الافتراضي:

```python
@router.callback_query(F.data.startswith("wiz_color:"))
async def on_wiz_color(callback, bot: Bot):
    uid = callback.from_user.id if callback.from_user else 0
    state = wizard_state.get(uid)
    if state is None or not _get_pending_audio_or_none(uid):
        await callback.answer(texts_module.MSG_WIZ_EXPIRED, show_alert=True)
        return
    choice = callback.data.split(":", 1)[1]
    if choice in ("pink", "blue", "yellow", "red", "green", "bloody", "purple"):  # 👈 أضف هنا
        developer_vinyl_choice[uid] = choice
    else:
        developer_vinyl_choice.pop(uid, None)
    await callback.message.edit_text(texts_module.MSG_WIZ_CHOOSE_SPEED, reply_markup=build_wiz_speed_keyboard())
    await callback.answer()
```

## 7) اختبار شامل (المسارين الاثنين)

**المسار الأول (/dev أو زر "🎨 لون القرص" من /start):**
- شغّل البوت، اضغط /start، اضغط زر "🎨 لون القرص" (`vinyl_menu:open`)
- تأكد اللون الجديد يظهر بالكيبورد
- اختره، تأكد يظهر ✅ جنبه بدون أي كراش

**المسار الثاني (معالج التخصيص — المكان اللي غالبًا كانت فيه المشكلة):**
- أرسل ملف صوتي للبوت
- اضغط "🎛 تخصيص" (مو "⚡ إنشاء سريع")
- بشاشة اختيار اللون، تأكد اللون الجديد ظاهر بالزر
- اضغطه وكمّل الخطوات (السرعة → الصورة → الإرسال)
- تأكد الفيديو الناتج فعلاً يستخدم `vinyl_purple.png` و `shadow_purple.png`
  (مو الأسود الافتراضي — لو رجع أسود يعني نسيت خطوة 5-ب: `on_wiz_color`)

**نصيحة عامة:** أي لون جديد لازم يتكرر بأربع أماكن بالضبط بملف handlers.py:
`get_developer_vinyl_path`, `get_developer_shadow_path`, `on_vinyl_choice`,
`build_vinyl_color_keyboard` — **بالإضافة** لمكانين إضافيين لو تبيه متاح
بمعالج التخصيص: `build_wiz_color_keyboard`, `on_wiz_color`. فوّت أي وحدة =
اللون يشتغل جزئيًا بس ويسبب لغبطة "ليش ما يشتغل؟".
